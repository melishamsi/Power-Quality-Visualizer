# Power Quality Parameters Visualizer

This project is a dynamic web dashboard designed to visualize and analyze electrical power quality parameters according to **TS EN 50160** standards. It was developed as part of an engineering internship project at **Gazi University**.

## 🚀 Features
* **Real-time RMS Monitoring:** Visualize voltage levels with nominal range checks (±10%).
* **Voltage Unbalance:** Vector diagram visualization and VUB percentage calculation.
* **Voltage Dips:** Time-profile analysis for industrial equipment sensitivity.
* **Harmonic Analysis (THD & Individual):** 7-channel spectrum analyzer for individual harmonics (H3-H15) and Total Harmonic Distortion.
* **Flicker Analysis:** 2-hour long-term flicker ($P_{lt}$) calculation from 12 $P_{st}$ measurements.

## 🛠 Tech Stack
* **Frontend:** HTML5, CSS3 (Modern Dark UI)
* **Visuals:** Chart.js, SVG for Vector Diagrams
* **Logic:** JavaScript (ES6)

## 📐 Standards
Compliant with **TS EN 50160** and **IEC 61000** series for technical quality measurements.
